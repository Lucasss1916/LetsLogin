Apex 配置工具 — Windows 三件套使用说明
════════════════════════════════════════════

【三个版本任选其一】
1. 完整 exe 图形版 (推荐): ApexConfigTool-win-x64.zip
   解压后运行 ApexConfigTool-win_x64.exe (仅约 2MB, Win10/11 自带 WebView2)
2. 控制台版: ApexCfgTool-win.zip (双击 Start.bat 进菜单, PowerShell 5.1+)
3. Python 脚本版: apex_cfg_tool.py (需 Python 3.8+, 命令行/菜单双模式)
   例: python apex_cfg_tool.py show / backup / restore -z <zip>

三版本格式互通: .apexcfg 分享文件、备份 zip、manifest、安全包均可互导。

【图形版快速上手】
1. 「本地配置」页: 逐行列出灵敏度/键位/画质全部键值, 顶部可筛选
2. 「备份与恢复」: 一键备份(指纹去重+轮转), 选中历史即可回滚
3. 「导出 / 导入」: 生成 .apexcfg 分享文件, 或应用他人的(自动安全包)
4. 「分享广场」: 登录 LetsLogin 账号(默认 http://127.0.0.1:3080, 可改),
   浏览/搜索广场配置, 查看全量键值明细, 一键导入或发布自己的配置
5. 窗口为无边框自绘标题栏: 右上角 ─ 最小化 / □ 最大化 / ✕ 关闭

【安全说明】
工具只读写 Saved Games\Respawn\Apex\local 下的 *.cfg / *.txt 配置文件。
每次恢复/导入前自动生成安全包(pre-*-*-*.zip), 原状态随时可回滚。

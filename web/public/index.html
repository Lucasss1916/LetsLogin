Apex 配置工具

⇩ Windows exe(免装 Python) ⇩ .py 源脚本

备份 / 恢复(本机)

  1. Windows 用户下载 exe(零依赖,下载即用);macOS / Linux 下载 .py(需 Python 3.8+,零第三方依赖)
  2. 打开 PowerShell / 终端,进入文件所在目录
  3. 备份当前配置:.\apex_cfg_tool.exe backup(.py 版为 python apex_cfg_tool.py backup)
  4. 查看备份列表:.\apex_cfg_tool.exe list
  5. 恢复备份:.\apex_cfg_tool.exe restore apex-backup-XXXX.zip

工具只读写 Saved Games\Respawn\Apex\local 下的 *.cfg / *.txt 配置文件(灵敏度、键位、画质);每次恢复前会自动给当前状态打安全包,可随时再恢复回去。
